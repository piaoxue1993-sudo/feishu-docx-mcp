# Script Art Design Analysis Experimental

面向电影、剧集与短剧项目的实验性剧本美术设计 Skill。它可以读取中文或英文剧本，完成场景拆解、地域与年代研究、美术方向分析、场景视觉提示词设计，并在需要时生成具有空间连续性的场景正面图、真实反打图以及本地 Word 场景图册。

## 核心能力

- 解析剧本中的正式场次，以及闪回、梦境、预见、监控画面、蒙太奇等嵌套场景。
- 合并重复地点并建立稳定的 `SPACE-ID`、`ZONE-ID` 和空间主控逻辑，避免同一地点在不同场次中被设计成互不相干的空间。
- 输出美术分析、色彩系统、材质语言、建筑逻辑、陈设方向、影视参考与完整场景清单。
- 为每个场景生成无人环境图提示词；可按日、夜、黎明、黄昏等状态分别设计完整布光。
- 生成正面图与真实反打图。反打不是水平镜像，而是移动摄影机到同一物理空间中的合理对向机位。
- 检查入口、门窗、楼梯、栏杆、走廊、固定家具、结构柱和室外视线等连续性，减少动线与建筑穿帮。
- 为别墅区、豪宅、庄园、山庄、度假村或大型建筑群先生成全场俯视／鸟瞰空间总览，再从总览推导局部场景和反打图。
- 使用影视化光源层级：一个明确的主光源，配合少量辅助光、轮廓光或场景实景灯，避免满画面无逻辑点光源。
- 默认采用干燥、哑光或半哑光地面，极致弱化地面反光，避免镜面倒影、灯带反射和装饰性亮斑。
- 输出可移交的本地 Word 场景图册与独立 `images/` 素材文件夹，不依赖飞书转换。

## 典型使用场景

- “分析这部芝加哥都市剧本，整理全部场景并生成场景图和反打图。”
- “为豪宅先建立完整鸟瞰总图，再生成门厅、客厅、书房和后院的连续机位。”
- “保持原建筑结构，重做反打角度，不要直接镜像。”
- “降低地面反光，使用单一主光源和好莱坞级写实布光。”
- “输出美术分析文档、场景清单、提示词和 Word 场景图册。”

## 工作流程

1. 读取完整剧本，识别正式场次、嵌套场景、时间状态和重复地点。
2. 建立物理空间注册表，确认同一空间、相连区域和独立场景之间的关系。
3. 输出项目美术方向，包括地域、年代、阶层、建筑、色彩、材质、陈设与光线逻辑。
4. 生成按首次出现顺序排列的合并场景清单。
5. 为每个场景建立空间主控，并生成环境图提示词。
6. 大型宅邸或建筑群先生成 `M##` 俯视／鸟瞰总览图；总览图不需要反打。
7. 从空间主控或总览图推导局部正面图，并立即生成同空间的真实反打图。
8. 审核正反打之间以及同一空间全部镜头之间的建筑、动线、光线与陈设连续性。
9. 将图片和说明嵌入 Word，同时保留规范命名的原始图片文件。
10. 运行校验脚本并检查最终 Word 版面后交付。

## 输出内容

根据用户需求，Skill 可交付以下内容：

- 剧本美术设计分析报告
- 合并后的场景清单
- 场景环境图生成提示词
- 大型场景鸟瞰空间总览图
- 各场景正面全景图／俯视全景图
- 与空间结构一致的反打图
- 本地 Word 场景图册
- 独立 `images/` 场景素材文件夹

普通场景图片采用稳定的 `S01`、`S02` 编号，反打图在主图文件名扩展名前增加 `—反`。大型场景空间总览采用 `M01_主场景－空间总览.png` 等命名，不生成对应反打图。

## 安装方法

1. 解压分享包。
2. 将完整的 `script-art-design-analysis-experimental` 文件夹复制到 Codex Skills 目录：

   ```text
   Windows: %USERPROFILE%\.codex\skills\
   macOS/Linux: ~/.codex/skills/
   ```

3. 确认最终结构如下：

   ```text
   ~/.codex/skills/script-art-design-analysis-experimental/
   ├── SKILL.md
   ├── agents/
   │   └── openai.yaml
   ├── references/
   │   ├── cinematic-lighting.md
   │   ├── image-generation-and-word-layout.md
   │   ├── output-spec.md
   │   └── spatial-continuity-and-reference-research.md
   └── scripts/
       └── validate_scene_word_atlas.py
   ```

4. 重新启动 Codex，或新建任务使 Skill 被重新发现。

## 使用方式

可以在请求中明确调用：

```text
使用 $script-art-design-analysis-experimental 分析这个剧本，生成场景美术方案、场景图和真实反打图。
```

也可以直接描述剧本美术分析、场景空间连续性、豪宅总览、正反打图或 Word 场景图册需求，由 Codex 自动匹配该 Skill。

## 使用注意事项

- 场景图默认不包含人物、演员、群众、剪影或身体局部。
- 反打图必须依据已确认的物理空间生成，不能用主图水平翻转代替。
- 同一场景不同时间状态必须保持建筑与固定陈设不变，但要重新设计符合时间状态的光源关系。
- 豪宅、庄园等大尺度场景的局部图必须能在总览图中定位，并保持楼层、道路、入口、庭院、楼梯和景观边界一致。
- 除非剧情明确要求雨水、冰面、镜面石材或其他反射介质，否则地面不得出现大面积或镜面式反光。
- 图片生成失败时应保留对应章节和提示词，并明确标记待重试，不使用虚假占位图冒充结果。
- 本 Skill 默认输出本地文件，不包含飞书文档转换流程。

## 包内文件说明

- `SKILL.md`：核心触发描述与完整执行流程。
- `agents/openai.yaml`：Codex 中显示名称、简介与默认调用提示。
- `references/cinematic-lighting.md`：影视布光与空气介质规范。
- `references/image-generation-and-word-layout.md`：图片生成和 Word 图册排版规范。
- `references/output-spec.md`：分析报告、场景表与提示词的输出结构。
- `references/spatial-continuity-and-reference-research.md`：空间连续性、真实反打和参考研究方法。
- `scripts/validate_scene_word_atlas.py`：检查 Word 图册、图片命名、主图／反打配对和嵌入完整性的校验脚本。

## 版本特征

当前分享版已经包含：大型宅邸／建筑群总览主控、局部镜头空间推导、非镜像真实反打、单一主光源优先的影视布光，以及极低地面反光控制。
