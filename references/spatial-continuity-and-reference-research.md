## 1. 生成前空间推理

为每个室内场景先建立简短的“空间连续性卡”，内部使用即可，无须默认展示给用户：

- 房间功能与建筑类型；
- 主图摄影机所在侧与观看方向；
- 主图可见的门、窗、楼梯、走廊口及固定构件；
- 主图没有拍到的墙面；
- 主要表演区与合理通行净空；
- 必需的主入口、次入口和相邻空间；
- 反打必须保留的 1–3 个连续性锚点；
- 反打需要揭示但不能与主图冲突的空间信息。

采用“硬事实 / 可推断 / 禁止改变”三级判断：

- 硬事实：剧本明确内容和主图中已经看见的结构，必须保持。
- 可推断：主图画外的墙面、入口、走廊或相邻空间，可按建筑逻辑补全。
- 禁止改变：已出现门窗、楼梯、柱、固定家具的位置、数量、方向和尺度，不得为了反打构图而改动。

## 2. 出入口补全规则

- 室内场景原则上必须存在功能可信的进入方式。主图未见入口不等于空间没有入口；优先在反打揭示的未见墙面补全。
- 住宅客厅通常关联玄关、走廊、院门或楼梯厅；卧室关联内走廊而非直接通向公共街道；办公室关联前厅、开放办公区或核心筒；餐厅后场关联备餐间或服务走廊。根据具体剧本和建筑类型判断，不机械套用。
- 检查门扇开启弧、推拉方向、门前净空、家具避让、墙厚、门套及门后的相邻空间。入口不能开在结构柱、整面玻璃、壁炉、固定柜体或被大型家具完全封堵的位置。
- 若主图已有合理入口，反打应从相反方向解释其连接关系，不得再随意增加第二个入户门。
- 若剧情需要多个出口、逃生关系、礼仪轴线、主仆分流或前后台分流，依据剧本明确表现；不要为了丰富画面擅自增加。
- 补全入口属于完成主图画外空间；不得改变主图可见结构，也不得把两个不相容的平面拼在一起。

## 3. 影视与建筑参考研究

生成项目图像前，针对项目整体和重点场景主动研究参考。可联网时优先使用电影官方剧照、制作设计师访谈、摄影师访谈、幕后花絮、建筑档案和可信出版物；不能联网时使用已有影视知识，但不得虚构出处。

每个项目先建立 3–6 个核心参考，每个关键场景再选 1–3 个最相关参考。选择维度包括：

- 国家、城市、气候和地域文化；
- 历史时期与建筑年代；
- 人物阶层、职业、家庭结构和生活痕迹；
- 住宅、酒店、医院、办公室、商铺、仓库等建筑类型；
- 场景的戏剧功能、情绪压力和镜头语言；
- 摄影棚搭建、实景改造或虚拟制作的可实施性。

只吸收空间组织、尺度、阈限、材质搭配、陈设密度、色彩比例、生活痕迹和光线组织等原则。不要复制单一影片中可识别的完整布景，不要只用片名或“某导演风格”代替具体设计描述。

在提示词中将参考转译为可执行语言，例如“狭长玄关形成压迫性门框套景”“公共区开敞、私人区通过低照度走廊后撤”“旧木门套与修补墙漆体现长期居住”，而不是简单写“像某某电影”。

## 4. 去模板化设计矩阵

同一项目内至少从以下维度组合出差异，避免所有空间千篇一律：

- 入口类型：深玄关、短前室、直接入厅、侧向门厅、门廊、院落过渡、楼梯平台、服务入口；
- 开启方式：内开、外开、双扇、推拉、折叠、旋转或无门套开口，必须符合场所与安全逻辑；
- 门体语言：实木、金属、玻璃、格栅、织物软隔断、历史门扇、工业防火门；
- 阈限层次：门槛、台阶、地材转换、压低吊顶、屏风、门斗、光线明暗转换；
- 平面关系：轴线进入、侧向进入、转折后进入、穿堂、环形回游、前后台分流；
- 使用痕迹：门把磨损、墙角碰痕、地面行走带、临时修补、礼仪性整洁或高频杂乱；
- 视觉密度：极简留白、日常克制、拥挤生活化、机构化秩序、权力空间的对称与尺度。

差异必须来自剧本、地域、年代、人物和建筑类型，不以随机装饰制造变化。同一建筑内部仍要共享门套体系、五金家族、踢脚线、墙体材料和尺度逻辑。

## 5. 反打自我优化循环

每次生成反打后执行以下循环，最多进行合理次数的定向重试：

1. 对照空间连续性卡，检查硬事实是否完整保留。
2. 检查反打新增入口是否只占用未见墙面，并与主图透视、墙体和家具关系兼容。
3. 检查入口后的相邻空间是否可信，而不是一扇通向黑洞或无意义贴墙门。
4. 检查主图与反打是否共享连续性锚点，且锚点方向符合相反机位。
5. 与本项目其他场景比较门型、材料、构图和陈设，发现模板化重复时，依据场景设计矩阵重新差异化。
6. 若任一项失败，只修正失败项，并继续使用已接受主图作为参考；不得用失败反打作为下一次参考源，避免误差累积。

完成后在内部记录：`空间闭环通过 / 连续性通过 / 入口合理 / 去模板化通过`。任一项未通过时，不得在 Word 图册中标记为完成。

## 6. 同一物理空间的多镜头一致性

### 6.1 先识别空间，再读取场景名

场景名是叙事标签，不是空间身份。生成前必须建立“物理空间身份表”，至少记录：

- `SPACE-ID`：整套物理环境的稳定编号；
- `ZONE-ID`：门口、工位、会客区、走廊等相连分区；
- 剧本别名：不同场次使用过的全部场景名；
- 同址证据：地址、人物连续移动、共同门窗、相同外景、固定家具或文字说明；
- 空间拓扑：各分区相邻关系和朝向；
- 固定锚点：柱网、卷帘门、窗、入口、楼梯、内置柜、主要大型家具；
- 规范正向与规范反向：该空间固定的两组相反观察方向；
- 已接受参考图：此空间后续生成必须引用的母版图。

即使名称分别是“修车店门口”“维修工位”“工作台看向大门”，只要剧本和视觉证据表明它们属于同一修车厂，就必须共享同一 `SPACE-ID`。它们可以是不同 `ZONE-ID` 或不同机位，但不得各自生成一套门、街景、柱网或工具墙。

### 6.2 锁定空间母版

同一 `SPACE-ID` 的第一组图片通过后，立即锁定空间母版：

1. 用简图或文字坐标明确四面墙、入口、窗、柱、楼梯和相邻分区；
2. 标记外部朝向与窗外/门外可见地标；
3. 标记固定陈设的位置、朝向和数量；
4. 建立摄影机节点，例如 `CAM-A 门口向内`、`CAM-B 室内向门口`、`CAM-C 工作台斜看工位`；
5. 为每个节点记录其规范反打节点，形成 `CAM-A ↔ CAM-B` 等固定关系。

后续场景名变化、剧情变化或焦段变化不得解除母版。只有剧本明确发生改建、破坏、搬空、重新布置、年代变化或地域变化时，才创建新的 `STATE-ID`，并记录变化来源。

### 6.3 跨图片生成规则

- 每次生成前先查询 `SPACE-ID`，不得按标题直接新建场景。
- 若已有空间母版，必须同时提供最能说明当前朝向的母版图和对应反向参考图；不能只依赖最近一张图片。
- 同一方向的多张主图，反打中的对侧墙、入口、窗外地标和固定陈设必须一致。允许变化的只有机位横移、镜头高度、焦段、遮挡和剧情要求的可移动小陈设。
- 同一空间不同分区的画面要通过共享开口、柱网、地材接缝、墙面材料、顶棚结构或外部地标互相定位。
- 不得把“视觉相似”误判为“一致”。同色墙面、同类工具柜或同风格家具不足以通过检查；必须能解释其在同一平面中的具体位置。
- 不得让反打在每次生成时重新猜测入口。入口一旦在任何已接受图片中确立，就成为硬事实。

### 6.4 跨组审查

完成一个 `SPACE-ID` 下的全部图片后，把该组所有主图与反打同时检查：

1. 每个机位能否放在同一张平面图上；
2. 每个反打是否指向同一个规范反向环境；
3. 门窗、柱网、顶棚梁、地材分缝、固定家具是否数量与方位一致；
4. 门外/窗外街景、建筑、桥梁、树木等是否保持同一朝向与相对位置；
5. 相连分区能否通过同一个门洞或走廊互相到达；
6. 是否出现“单独看合理、组合后互相矛盾”的图片。

任一项失败，回退到已接受的空间母版，从正确摄影机节点定向重生成失败图。禁止以失败图作为新参考继续扩散误差。最终内部记录：`SPACE-ID 跨组连续性通过`。
